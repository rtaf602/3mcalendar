# 3M Calendar · Master Plan ฝูง.602

ปฏิทินรวมภารกิจ + แผนซ่อมบำรุงอากาศยาน ห้วง 3 เดือนนับจากเดือนปัจจุบัน
หน้าเว็บอยู่บน GitHub Pages ข้อมูลอยู่ใน Google Sheets ผ่าน Google Apps Script

- หน้าเว็บ: https://rtaf602.github.io/3mcalendar/
- เข้าใช้งานด้วย **ชื่อผู้ใช้งาน + รหัสเปิดใช้งาน** (ตรวจที่ฝั่ง Google) ใช้ได้ครั้งละ 1 ชั่วโมง
- แก้ไขได้ทีละคน คนอื่นเปิดดูพร้อมกันได้ และเห็นว่าใครกำลังแก้ช่องไหน

## ไฟล์และหน้าที่

| ไฟล์ | หน้าที่ |
|---|---|
| `3m_calendar ปีงบ70_ต้นทาง` (Google Sheet) | ฐานข้อมูลจริง หน้าเว็บอ่าน/เขียนที่นี่เท่านั้น (แท็บ events, months, settings, logs, snapshots) |
| `3m_calendar ปีงบ70_แสดงผล` (Google Sheet) | ปฏิทิน 3 เดือนแบบไฟล์ Excel เดิม ระบบวาดใหม่หลังทุกการแก้ไข (ภายในไม่กี่วินาที) ใช้ดู/พิมพ์/แชร์ แก้ในไฟล์นี้ไม่มีผล |
| โฟลเดอร์ `3mcalendar Backup` | ทุกครั้งที่กด SAVE เก็บไฟล์ Excel `ปีเดือนวัน_รวม_ภารกิจ+แผนซ่อมบำรุง_เวลา TH-LT.xlsx` ไว้ 20 ไฟล์ล่าสุด ไฟล์เก่ากว่านั้นย้ายไปถังขยะ |
| `index.html`, `config.js`, `fonts/` | หน้าเว็บ (GitHub Pages) |
| `apps-script/Code.gs` | โค้ดฝั่ง Google (วางใน Apps Script ของไฟล์ต้นทาง) |

> repo นี้เป็นสาธารณะ ห้ามใส่ข้อมูลแผนภารกิจลงใน repo ข้อมูลอยู่ใน Google Sheet เท่านั้น

## ติดตั้งครั้งแรก (ประมาณ 10 นาที)

ใช้บัญชี Google ที่เป็นเจ้าของ (หรือแก้ไขได้) ทั้งไฟล์ต้นทาง ไฟล์แสดงผล และโฟลเดอร์ Backup

1. เปิดไฟล์ **3m_calendar ปีงบ70_ต้นทาง** > เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. (ครั้งแรกเท่านั้น) กด **+ > Script** ตั้งชื่อ `Seed` แล้ววางเนื้อหาไฟล์ `Seed.gs` ที่ได้รับแยกต่างหาก (ข้อมูลแผนปัจจุบัน ไม่อยู่ใน repo)
4. กด 💾 บันทึก เลือกฟังก์ชัน **setup** ที่แถบบน แล้วกด **Run**
   - Google จะขอสิทธิ์: กด Review permissions > เลือกบัญชี > Advanced > Go to … (unsafe) > Allow
   - รอจนบันทึกการทำงานขึ้นว่า "ตั้งค่าเสร็จแล้ว" ไฟล์ต้นทางจะมีแท็บข้อมูล และไฟล์แสดงผลจะมีปฏิทิน
5. กด **Deploy > New deployment** > รูปเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. ใส่ URL ในไฟล์ [`config.js`](config.js) ของ repo นี้ (`apiUrl: 'https://script.google.com/macros/s/…/exec'`) แล้ว commit
7. ลบไฟล์ `Seed` ใน Apps Script ทิ้งได้ (นำเข้าแล้ว)
8. เปิด https://rtaf602.github.io/3mcalendar/ ใส่ชื่อและรหัสเปิดใช้งาน

## แก้โค้ดฝั่ง Google ภายหลัง

วางโค้ดใหม่ใน Apps Script > **Deploy > Manage deployments** > ✏️ > Version: **New version** > Deploy
(URL เดิมใช้ต่อได้ ไม่ต้องแก้ config.js)

## งานดูแลที่ทำได้ใน Apps Script

| ฟังก์ชัน | ใช้เมื่อ |
|---|---|
| `setAccessCode` | เปลี่ยนรหัสเปิดใช้งาน: แก้ `NEW_CODE` ในฟังก์ชันแล้วกด Run (คนที่เข้าอยู่ใช้ต่อได้จนครบ 1 ชั่วโมง) |
| `clearEditLock` | ปลดสิทธิ์แก้ไขที่ค้าง (ปกติปลดเองภายใน 90 วินาที) |
| `renderDaily` | วาดไฟล์แสดงผลใหม่ทันที |

ตัวตั้งเวลาที่ `setup` สร้างให้: วาดไฟล์แสดงผลทุก 1 นาทีถ้ามีการแก้ไขค้าง, วาดใหม่ทุกวันเวลา 00:05 (แถบแดงวันที่ผ่านไปแล้วเลื่อนตามวัน), ลบประวัติการแก้ไขที่เก่ากว่า 1 ปีทุกวันเวลา 02:00
