# 3M Calendar · Master Plan ฝูง.602

ปฏิทินรวมภารกิจ + แผนซ่อมบำรุงอากาศยาน ห้วง 3 เดือนนับจากเดือนปัจจุบัน
หน้าเว็บอยู่บน GitHub Pages ข้อมูลอยู่ใน Google Sheets ผ่าน Google Apps Script

- หน้าเว็บ: https://rtaf602.github.io/3mcalendar/
- เข้าใช้งานด้วย **ระบบ Login กลาง ฝูง.602** (repo [`eadmin`](https://github.com/rtaf602/eadmin)) ไม่มีรหัสเปิดใช้งานของเว็บนี้แล้ว
  - ใครเข้าได้และเป็น Role อะไร Admin หลักกำหนดในหน้า Admin ส่วน "สิทธิ์เข้าใช้งานเว็บ" (รหัสเว็บ `WEB1`)
  - Admin / Editor: ดู แก้ไข ปิดงาน / ออกฉบับ ส่งออก PDF / Excel · Viewer: ดูอย่างเดียว ส่งออกไม่ได้ · ไม่มีสิทธิ์: เข้าไม่ได้
  - ระบบหลังบ้านของเว็บนี้ถามระบบ Login ทุกคำขอ (การแก้ไขถามทุกครั้ง การดูถามซ้ำทุก 1 นาที)
  - ชื่อผู้บันทึกในประวัติการแก้ไข (รวมการ EXPORT TO PDF / EXCEL) คือ ชื่อ-สกุล ของบัญชีที่ Login ตามชีท LOGIN DATABASE
- แก้ไขได้ทีละคน คนอื่นเปิดดูพร้อมกันได้ และเห็นว่าใครกำลังแก้ช่องไหน

## ติดตั้งครั้งแรก (ประมาณ 10 นาที)

ใช้บัญชี Google ที่เป็นเจ้าของ (หรือแก้ไขได้) ทั้งไฟล์ต้นทาง ไฟล์แสดงผล และโฟลเดอร์ Backup

1. เปิดไฟล์ **3m_calendar ปีงบ70_ต้นทาง** > เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. (ครั้งแรกเท่านั้น) กด **+ > Script** ตั้งชื่อ `Seed` แล้ววางเนื้อหาไฟล์ `Seed.gs` ที่ได้รับแยกต่างหาก (ข้อมูลแผนปัจจุบัน ไม่อยู่ใน repo)
4. ในส่วน `CFG` ด้านบนของโค้ด กรอก `LOGIN_URL` เป็นที่อยู่ระบบหลังบ้านของระบบ Login กลาง (ค่า `backendUrl` ในไฟล์ `docs/assets/config.js` ของ repo eadmin)
   และตรวจว่า `WEB_CODE` ตรงกับรหัสเว็บในรายชื่อเว็บของหน้า Admin และตรงกับ `webCode` ในไฟล์ `config.js` ของ repo นี้
5. กด 💾 บันทึก เลือกฟังก์ชัน **setup** ที่แถบบน แล้วกด **Run**
   - Google จะขอสิทธิ์: กด Review permissions > เลือกบัญชี > Advanced > Go to … (unsafe) > Allow
   - Google จะขอสิทธิ์ "Connect to an external service" เพิ่ม (ใช้ถามระบบ Login) ให้กด Allow
   - รอจนบันทึกการทำงานขึ้นว่า "ระบบ Login ตอบแล้ว" และ "ตั้งค่าเสร็จแล้ว" ไฟล์ต้นทางจะมีแท็บข้อมูล และไฟล์แสดงผลจะมีปฏิทิน
6. กด **Deploy > New deployment** > รูปเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
7. ใส่ URL ในไฟล์ [`config.js`](config.js) ของ repo นี้ (`apiUrl: 'https://script.google.com/macros/s/…/exec'`) แล้ว commit
8. ลบไฟล์ `Seed` ใน Apps Script ทิ้งได้ (นำเข้าแล้ว)
9. เปิด https://rtaf602.github.io/3mcalendar/ ระบบจะพาไปหน้าเข้าสู่ระบบกลาง แล้วพากลับมาที่ปฏิทินหลัง Login

## แก้โค้ดฝั่ง Google ภายหลัง

วางโค้ดใหม่ใน Apps Script > **Deploy > Manage deployments** > ✏️ > Version: **New version** > Deploy
(URL เดิมใช้ต่อได้ ไม่ต้องแก้ config.js)
ที่อยู่ระบบ Login ที่เคยกรอกใน `CFG.LOGIN_URL` ระบบจำไว้แล้ว โค้ดรุ่นใหม่ปล่อยช่องนี้ว่างได้

## เปลี่ยนจากรหัสเปิดใช้งานมาใช้ระบบ Login กลาง (ครั้งเดียว)

1. หน้า Admin ของระบบ Login: Admin หลักเพิ่มเว็บนี้ในส่วน "รายชื่อเว็บ" (รหัสเว็บ `WEB1`) และให้สิทธิ์แต่ละบัญชี (Admin / Editor / Viewer)
2. Apps Script ของไฟล์ต้นทาง: วางโค้ดใหม่ กรอก `CFG.LOGIN_URL` แล้ว Run **setup** (ข้อ 4–5 ด้านบน) แล้ว Deploy เป็น New version
3. GitHub: กด Merge ที่ Pull Request ของ repo นี้ (ต้องทำหลังข้อ 2 ถ้าทำก่อน หน้าเว็บจะส่งบัตรผ่านแต่โค้ดฝั่ง Google ยังรอรหัสแบบเดิม)
4. รหัสเปิดใช้งานเดิมเลิกใช้ทันทีที่ทำข้อ 2 (`setup` ลบค่าที่เก็บไว้) แต่ยังอยู่ในประวัติของ repo ที่เป็นสาธารณะ จึงไม่ควรนำรหัสนั้นไปใช้ที่อื่น

## งานดูแลที่ทำได้ใน Apps Script

| ฟังก์ชัน | ใช้เมื่อ |
|---|---|
| `clearEditLock` | ปลดสิทธิ์แก้ไขที่ค้าง (ปกติปลดเองภายใน 90 วินาที) |
| `renderDaily` | วาดไฟล์แสดงผลใหม่ทันที |

ตัวตั้งเวลาที่ `setup` สร้างให้: วาดไฟล์แสดงผลทุก 1 นาทีถ้ามีการแก้ไขค้าง, วาดใหม่ทุกวันเวลา 00:05 (แถบแดงวันที่ผ่านไปแล้วเลื่อนตามวัน), ลบประวัติการแก้ไขที่เก่ากว่า 1 ปีทุกวันเวลา 02:00
